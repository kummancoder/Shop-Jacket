# Jacket Shop Web Page

This project is a simple web design showcasing a product page for a jacket. The design is built using **HTML** and **CSS**, featuring a clean, minimalistic interface.

---

## Features

- **Minimalistic Design**: Clean, user-friendly layout to enhance the user experience.
- **Product Description**: A detailed description of the jacket is prominently displayed.
- **Interactive Options**:
  - Buttons for adding the product to the cart.
  - Viewing detailed product information.
  - Exploring shopping options.
- **Responsive Navigation**: A navigation bar with options such as **About**, **News**, and **Cart**.
- **Visual Appeal**: Features a large, high-quality product image for better aesthetics.
